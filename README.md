# 📌 Telegram Доска объявлений

Полностью функциональный Telegram-бот для размещения и просмотра объявлений с поддержкой категорий, админ-панели и системой жалоб.

## 🚀 Функциональность

- ✅ **Размещение объявлений** с выбором категории
- ✅ **Просмотр объявлений** по категориям
- ✅ **Контакт с автором** - никнейм автора кликабелен, можно писать в ЛС одним нажатием
- ✅ **Мои объявления** - управление собственными объявлениями
- ✅ **Система жалоб** - пожаловаться на неподобающие объявления
- ✅ **Админ-панель** - удаление объявлений, блокировка пользователей
- ✅ **База данных** - все данные хранятся безопасно в PostgreSQL (Neon)

## 📋 Категории объявлений

- 📱 Электроника
- 👕 Одежда

## 🛠️ Технический стек

- **Python 3.9+**
- **aiogram 3.x** - асинхронный Telegram бот фреймворк
- **asyncpg** - асинхронный драйвер для PostgreSQL
- **Neon** - облачная база данных PostgreSQL
- **Render** - хостинг для бота (24/7)

## ⚙️ Установка и настройка

### Шаг 1: Клонируем репозиторий

```bash
git clone https://github.com/YOUR_USERNAME/vsev1dmd_bot.git
cd vsev1dmd_bot
```

### Шаг 2: Устанавливаем зависимости

```bash
pip install -r requirements.txt
```

### Шаг 3: Настраиваем переменные окружения

Копируем файл примера:
```bash
cp .env.example .env
```

Открываем `.env` и вставляем:

```
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
DATABASE_URL=postgresql://user:password@ep-xxxxx.us-east-2.aws.neon.tech/neondb?sslmode=require
ADMIN_IDS=ВАШ_TELEGRAM_ID
```

### Шаг 4: Запускаем бота локально (для тестирования)

```bash
python main.py
```

## 🚀 Развертывание на Render

### 1. Создаем новый сервис на Render

- Откройте https://render.com
- Нажмите "New +" → "Web Service"
- Подключите репозиторий GitHub

### 2. Настраиваем сервис

**Build Command:**
```
pip install -r requirements.txt
```

**Start Command:**
```
python main.py
```

### 3. Добавляем переменные окружения

В разделе "Environment" добавляем:

| Ключ | Значение |
|------|----------|
| `BOT_TOKEN` | Ваш токен от BotFather |
| `DATABASE_URL` | Connection String из Neon |
| `ADMIN_IDS` | Ваш Telegram ID (и других админов через запятую) |

**Важно:** не делитесь этими значениями ни с кем!

### 4. Запускаем сервис

Нажимаем "Create Web Service" — бот начнет работать 24/7! 🚀

## 📖 Как пользоваться ботом

### Обычный пользователь

1. **/start** - открыть главное меню
2. **📝 Разместить объявление** - создать новое объявление
3. **🔍 Смотреть объявления** - просмотреть объявления по категориям
4. **📌 Мои объявления** - управлять своими объявлениями
5. **💬 Написать** - написать автору в ЛС (автоматическая ссылка на его профиль)
6. **❌ Пожаловаться** - отправить жалобу на объявление

### Админ

Те же функции + **⚙️ Админ-панель**:
- 🗑️ Удалить объявление
- 🚫 Заблокировать пользователя
- 📊 Просмотреть статистику

## 🗄️ Структура базы данных

### Таблица `users`
- `id` - уникальный ID
- `telegram_id` - ID пользователя в Telegram
- `username` - никнейм пользователя
- `created_at` - дата регистрации
- `is_banned` - забанен ли пользователь

### Таблица `ads`
- `id` - уникальный ID объявления
- `user_id` - ID автора объявления
- `username` - никнейм автора (кликабельный)
- `category` - категория объявления
- `title` - название
- `description` - описание
- `price` - цена
- `created_at` - дата создания
- `is_active` - активно ли объявление

### Таблица `admins`
- `id` - уникальный ID
- `telegram_id` - ID админа в Telegram
- `added_at` - дата добавления в админы

### Таблица `reports`
- `id` - уникальный ID жалобы
- `ad_id` - ID объявления
- `reporter_id` - ID того, кто пожаловался
- `reason` - причина жалобы
- `created_at` - дата жалобы

## 🔐 Безопасность

- ✅ Токены и пароли **никогда** не видны в коде
- ✅ Database URL зашифрована и хранится только в Render
- ✅ Все данные передаются по защищенному каналу (HTTPS)
- ✅ Никнейм автора защищен от спама благодаря встроенной системе Telegram
